# ProfexHub / ZXKAI — Vercel-ready demo

This version is a static Vercel deployment. It uses browser JavaScript, so no PHP/MySQL server is required.

## Deploy to Vercel
1. Create a GitHub repository.
2. Upload the contents of this folder (not the ZIP itself).
3. In Vercel, import that GitHub repository.
4. Framework Preset: Other.
5. Deploy.

## Flow
Home → New Account → Upload Script/Config → Result → numbers found in the uploaded file → Copy.

The parser runs in the browser and only reads the file the user selects. It does not access SMS, OTP inboxes, Firebase accounts, or external devices.

## Supported upload
JS, JSON, TXT, HTML, XML and PHP text files.
