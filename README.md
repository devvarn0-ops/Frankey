# ZXKAI Responsive UI Recreation

GitHub-ready static recreation of the supplied ZXKAI Admin Console screenshots.

## Included states
- Landing / Saved Accounts
- New Firebase Account modal
- Device dashboard
- Device detail drawer/panel
- Responsive mobile + desktop layouts

## Run
Open `index.html` directly, or use any static server.

Example:
```bash
python -m http.server 8080
```

Then visit `http://localhost:8080`.

## Important
This is a **UI recreation based on the screenshots supplied by the user**, not an extraction of the original Vercel/GitHub source code. Firebase/API functionality is intentionally demo-only; no real credentials are stored or transmitted.
